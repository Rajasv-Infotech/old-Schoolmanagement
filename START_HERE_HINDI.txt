   Targeting pack: .NET Framework 4.8

4) 1-Download-Prerequisites.cmd run karein.

5) 2-Build-Setup.cmd run karein.

6) Final client file yahan milegi:
   artifacts\installer\RajasvSchoolSetup.exe

7) Detailed guide:
   Docs\SETUP_GUIDE_HINDI.md
